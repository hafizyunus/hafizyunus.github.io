## Owner's reference
**[tanqinghua.asia](https://www.tanqinghua.asia/)**
- Fixed left nav (about / works / talks / contact), lots of whitespace, near-monochrome.
- Hand-drawn doodle illustrations that change per page, which gives it personality without clutter.
- Small, soft typography; wavy underline on the active nav item.
- Works page is a simple 2-column grid of title + one-line description.
- Gap for us: no deep content pages. We need to add long-form technical layouts.

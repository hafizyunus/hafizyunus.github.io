## Context

Data centers need a lot of reliable backup power, and Caterpillar's generator sets
(gensets) are getting bigger to match. Every new genset package goes through
**new product introduction (NPI)** validation before it ships, and vibration is one of
the things that has to be proven safe.

## Analysing the data

I work as a vibration data analyst across several NPI projects. For each one I compare
three sources:

1. **FEA predictions** for the new design
2. **Test data from existing products** as a baseline
3. **Validation test data** from the new product

Putting them side by side shows whether the new package performs as expected and helps
define acceptance criteria.
